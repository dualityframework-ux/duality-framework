Method

Result = process + variance.

Every tool here follows the same three steps, the same way I root-cause an inventory variance at work.

  1. Observation

    State what happened, plainly, with the number.

  2. Mechanism

    Find the driver underneath it, and separate it from noise.

  3. Implication

    Say what it means for the next decision.

Observation: the 2024 Red Sox finished 81–81. Mechanism: run differential was neutral, so the record matched the process. Implication: an average team got an average result; nothing to chase or excuse.
